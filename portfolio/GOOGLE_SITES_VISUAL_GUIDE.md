# Google Sites: images and page flow

These steps are for assembling the portfolio in Google Sites; they are not displayed on the portfolio's pages.

## Download and add the images

1. Open [the labelled image gallery](assets/banners/README.md).
2. Click the image for the page you are editing. Download the original PNG using GitHub's download button; if you open the original image in a browser, save that image.
3. In Google Sites, select the page header, then **Change image → Upload** and choose the matching PNG.
4. Choose a **Banner** or **Large banner** header. Adjust the crop/focal point so the creative objects remain visible. Check both desktop and phone previews.
5. Put the page title over the calmer left area. Use Google Sites' readability adjustment or a separate text section if the title is hard to read. Do not sacrifice legibility for a background effect.
6. Add an image description/alt text where the editor supports it. The gallery includes a short description for every image.

The images match a cream, forest-green, terracotta, sage and lilac palette. They are AI-generated decorative banners, not photographs of the student's possessions or evidence of completed coursework. The separate instructional diagrams remain the material to use for precise definitions and comparisons.

## Create a smooth flow between pages

Google Sites does not provide a native control for custom cross-page fade or slide transitions. Recreate the visual continuity with matching headers, recurring section colours, consistent spacing and linked Previous/Next buttons. Embedding animation affects only that embed, not transitions between Google Sites pages.

Use **Insert → Button**, type a descriptive label, and choose the relevant site page as its destination. Place the forward button at the end of the content and a smaller previous-page button beside it.

## Transition between sections within a page

- Start with the banner, then place a short introduction on a plain cream background.
- Follow an explanation with a visual example; add one sentence explaining what to notice.
- Use a pale sage or lilac section background to signal a new topic, rather than a different bright colour for every paragraph.
- Use the same section spacing and heading styles across all pages. A thin divider can separate a major topic.
- Place optional technical detail in collapsible text and keep required definitions visible.
- Use a single-column arrangement when a phone preview makes two columns too cramped.

The separate HTML website has Previous/Next links and a short native cross-page fade in browsers that support view transitions. Other browsers use ordinary navigation. Reduced-motion preferences disable the fade. Those effects do not automatically transfer to Google Sites.

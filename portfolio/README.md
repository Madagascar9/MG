# Graphics design portfolio

Nine static HTML pages based on the uploaded portfolio assignment. No packages or build are required.

Run from this directory:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

For local use, open `index.html` directly. All assets are local. Deploy the contents of this directory to a static host; no hosting deployment has been performed.

## Before submission

- Confirm the submission date in `author.html`. Student, course, institution and instructor are filled from the supplied details.
- Add the student's actual eight course artifacts to the Home page collection. For each, include the actual tools used and a brief skill explanation. Do not describe the generated theory illustrations as coursework.
- Verify the legal overview against Jamaica's current Copyright Act and amendments. JIPO and WIPO access was blocked, so these remain explicitly unconsulted references. Two official MDN technical guides were consulted for image-format and contrast guidance.
- Add consistent references for every source, image, video and font actually used.
- Review all AI-assisted explanations and follow the instructor's authorship rules.

Sites was requested but no Sites tools were available in the session. These files are a local fallback, not a Sites project or a published website.

## Expanded content

The content pages now include applied design analysis, typography guidance, colour models, palette relationships, a palette explorer, resolution and export guidance, a motion demonstration, legal-use scenarios, practical-artifact reflection prompts and referenced technical explanations. Tables of contents are generated for longer pages. Motion starts paused and respects reduced-motion preferences.

`GOOGLE_SITES_CONTENT.md` contains the page text for copying into the Google Sites editor. Images and interactive features must be recreated or embedded using supported Google Sites features; this repository does not automatically update Google Sites.

## Checks completed

Browser checks covered all eight pages at desktop and mobile widths, navigation, mobile-menu operation, section anchors, four palette choices, motion play/pause, reduced-motion behaviour and JavaScript errors. All checks passed in the current environment.


## Visual presentation

The responsive design uses an original geometric cover illustration, a cream/forest-green base with sage, peach, lilac and gold accents, illustrated navigation cards, section motifs, and clearly labelled category covers for the pending coursework. Covers are decorative category markers rather than completed student artifacts. All assets remain local, with no external font or image dependency.

The eight project categories, design-skills overview and animation teaching demonstration are on `artefacts.html`. The Home page links to that collection. The primary navigation contains nine pages.

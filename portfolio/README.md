# Graphics design portfolio

Nine static HTML pages based on the uploaded portfolio assignment. No packages or build are required.

Run from this directory:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

For local use, open `index.html` directly. All assets are local. The portfolio is published at https://madagascar9.github.io/MG/portfolio/index.html .

## Before submission

- Review the Author page biography and confirmed student, course, institution and instructor details.
- Add the student's actual seven course artifacts to the Artefacts page collection. For each, include the actual tools used and a brief skill explanation. Do not describe the generated theory illustrations as coursework.
- Verify the legal overview against Jamaica's current Copyright Act and amendments. JIPO and WIPO access was blocked, so these remain explicitly unconsulted references. Two official MDN technical guides were consulted for image-format and contrast guidance.
- Add consistent references for every source, image, video and font actually used.
- Review all AI-assisted explanations and follow the instructor's authorship rules.

Sites was requested but no Sites tools were available in the session. These files power the GitHub Pages website; they are not a Google Sites project.

## Expanded content

The content pages now include applied design analysis, typography guidance, colour models, palette relationships, a palette explorer, resolution and export guidance, legal-use scenarios, practical-artifact reflection prompts and referenced technical explanations. Tables of contents are generated for longer pages. Page transitions respect reduced-motion preferences.

`GOOGLE_SITES_CONTENT.md` contains the page text for copying into the Google Sites editor. Images and interactive features must be recreated or embedded using supported Google Sites features; this repository does not automatically update Google Sites.

## Checks completed

Browser checks cover all nine pages at desktop and mobile widths, navigation, mobile-menu operation, section anchors, four palette choices, reduced-motion behaviour and JavaScript errors. All checks passed in the current environment.


## Visual presentation

The responsive design uses an original geometric cover illustration, a cream/forest-green base with sage, peach, lilac and gold accents, illustrated navigation cards, section motifs, and clearly labelled category covers for the pending coursework. Covers are decorative category markers rather than completed student artifacts. All assets remain local, with no external font or image dependency.

The seven project categories and design-skills overview are on `artefacts.html`. The Home page links to that collection. The primary navigation contains nine pages.

## Page images and navigation

`assets/banners/README.md` is the labelled gallery of nine AI-generated photographic-style banners. `GOOGLE_SITES_VISUAL_GUIDE.md` explains how to download the files, use them in Google Sites, and create a consistent page-to-page flow. These banners are separate from the practical coursework.

The local HTML site includes Previous/Next links and progressive cross-document view transitions. Supporting browsers use a short fade; other browsers keep ordinary navigation. Reduced-motion preferences disable the effect. Google Sites does not inherit these CSS effects.
